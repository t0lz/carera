# CARERA

Веб-приложение для учета автотранзакций с поддержкой импорта автомобилей и расчета таможенных платежей.

CARERA позволяет просматривать каталог автомобилей, создавать объявления, оформлять заявки на заказ автомобиля из-за границы, рассчитывать предварительную стоимость ввоза и отслеживать статусы заявок.

## Возможности

- Каталог автомобилей с карточками объявлений.
- Фильтрация автомобилей по основным параметрам.
- Регистрация и авторизация пользователей.
- Создание объявлений о продаже автомобилей.
- Загрузка и отображение фотографий объявлений.
- Оформление заявки на импорт автомобиля.
- Расчет таможенного сбора, пошлины, акциза, НДС и утилизационного сбора.
- Просмотр заявок на импорт и изменение их статусов.
- Разграничение возможностей по ролям: пользователь, менеджер, администратор.
- Управление справочниками марок, моделей и типов кузова.

## Технологии

- **Клиент:** HTML, CSS, JavaScript.
- **Сервер:** Node.js, Express.
- **База данных:** PostgreSQL на платформе Supabase.
- **Работа с БД:** библиотека `pg`.
- **Хранение данных пользователя на клиенте:** `localStorage`.
- **Тестирование API:** Postman.

## Установка и запуск

Требуется Node.js и доступ к базе данных Supabase/PostgreSQL.

```bash
cd api
npm install
npm start
```

После запуска сервер доступен по адресу:

```text
http://localhost:8080
```

Клиентские страницы раздаются сервером из папки `public`.

## Настройка базы данных

Проект использует PostgreSQL на платформе Supabase. В базе данных должны быть созданы таблицы:

- `roles`
- `users`
- `car_makes`
- `car_models`
- `body_types`
- `vehicles`
- `ads`
- `ad_photos`
- `import_orders`
- `customs_calculations`

Строка подключения к базе данных указывается в файле `api/db.js`. Для демонстрации и передачи проекта рецензенту пароль и другие секретные данные не следует публиковать в открытом виде.

## Назначение проекта

CARERA предназначена для демонстрации дипломного проекта по теме разработки информационной системы учета автотранзакций с импортом и таможенным расчетом для ООО «Трансфер». Система объединяет каталог автомобилей, объявления, заявки на импорт и расчет обязательных платежей в одном веб-приложении.
